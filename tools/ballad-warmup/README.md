# 발라드 워밍업

발라드를 부르기 전후의 목 관리를 한국어 음성과 기준음으로 따라 하는 설치형 웹앱(PWA)입니다.

루틴은 화면 위쪽에서 고릅니다.

- 워밍업(약 16분): 근육 스트레칭, 호흡, 성대 예열, 비강·공명, 발라드 특화, 마무리
- 톤 만들기(약 6분): 목 안 공간, 앞 공명, 모음 모양, 숨 섞기, 진성-가성 연결, 내 톤 찾기
- 성시경 스타일(약 7분): 따뜻하고 힘 뺀 발라드 톤의 방향을 잡는 연습. 특정 가수와 똑같이 만드는 연습이 아닙니다.
- 쿨다운(약 7분): 발성으로 내려오기, 마무리 스트레칭, 호흡 정리와 휴식

- 주소: https://hey7995.github.io/tools/ballad-warmup/
- 아이폰: Safari로 열고 공유 버튼 → "홈 화면에 추가"
- 안드로이드: Chrome으로 열고 메뉴 → "앱 설치"
- 컴퓨터: Chrome 또는 Edge 주소창의 설치 아이콘

한 번 열어 두면 인터넷 없이도 실행됩니다.
파일을 고쳐서 다시 올릴 때는 `sw.js` 맨 위의 `CACHE` 이름 숫자를 올려야 폰에 변경이 반영됩니다.
