# 발라드 워밍업

발라드를 부르기 전 목풀기 루틴을 한국어 음성과 기준음으로 따라 하는 설치형 웹앱(PWA)입니다.

- 주소: https://hey7995.github.io/ballad-warmup/
- 아이폰: Safari로 열고 공유 버튼 → "홈 화면에 추가"
- 안드로이드: Chrome으로 열고 메뉴 → "앱 설치"
- 컴퓨터: Chrome 또는 Edge 주소창의 설치 아이콘

한 번 열어 두면 인터넷 없이도 실행됩니다.
파일을 고쳐서 다시 올릴 때는 `sw.js` 맨 위의 `CACHE` 이름 숫자를 올려야 폰에 변경이 반영됩니다.
